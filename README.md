# GSAP Website – Interactive Animation Showcase

## 🚀 Project Overview

A high-performance interactive web application showcasing advanced animation techniques using the GreenSock Animation Platform (GSAP). Built with React and Vite, this project demonstrates modern frontend development practices with a focus on smooth, performant user experiences and polished visual interactions.

**Live Demo:** [gsap-website-silk.vercel.app](https://gsap-website-silk.vercel.app)

---

## 🛠️ Technical Architecture

- **Frontend Framework:** React with Vite for optimized development and production builds
- **Animation Engine:** GSAP (GreenSock Animation Platform) for professional-grade animations
- **Build Tool:** Vite with Hot Module Replacement (HMR)
- **Code Quality:** ESLint configured for maintainable, standards-compliant code
- **Deployment:** Vercel for seamless CI/CD and global CDN distribution

## 🧑‍💻 Getting Started

### Prerequisites
- Node.js (14.0 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Sathwik-Devireddy/gsapWebsite.git
cd gsapWebsite

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🔧 Configuration

### ESLint

For production applications, consider enabling TypeScript with type-aware lint rules. Check the official [Vite TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for more details.

### React Compiler

The React Compiler is not enabled by default due to its impact on dev & build performance. To enable it, see the [React Compiler documentation](https://react.dev/learn/react-compiler/installation).
